Core Architecture

Engineered for Open-World Scale

Everything required to simulate an entire living metropolis while concentrating computing power precisely where the player or camera is looking.

Macroscopic Fundamental Diagrams

Supports exact formulations of Greenshields parabolic flow, Newell simplified triangular, and trapezoidal capacity plateaus. Evaluates backward shockwave propagation speed \(w\) using the exact Rankine-Hugoniot jump condition to model realistic jam formation.

  • ✓ Greenshields: \(q(k) = v_f (k - k^2/k_j)\)
  • ✓ Newell Triangular: \(q(k) = \min(v_f k, w(k_j - k))\)
  • ✓ Rankine-Hugoniot shockwave jump condition

Directed Road Graph Network

Directed links model physical road segments with length \(L\), multiple lanes, and finite storage capacity \(K = k_j \cdot L \cdot \text{lanes}\). Includes signalized intersections with 4-phase signal timing, queue spillback, and aggregated flow packet propagation.

  • ✓ Physical storage capacity & jam density limits
  • ✓ Upstream queue spillback across junctions
  • ✓ Aggregated flow packets (N cars as 1 entity)

Dynamic Delay Routing

Fast Dijkstra and \(A^*\) pathfinding engines calculate optimal routes based on dynamic congestion travel times rather than static road lengths. Vehicles autonomously re-route around unexpected bottlenecks, accidents, and temporary lane closures.

  • ✓ Cost metrics: Congestion delay, Free-flow, Distance
  • ✓ Dynamic bottleneck avoidance & detouring
  • ✓ High-frequency online path recomputation

Background Render Bubble Handoff

The RenderBubble spatial system continuously detects when macroscopic vehicles approach the player camera. Extracts precise 2D world position, forward heading, lane index, and speed for Bevy ECS or microscopic physics, then cleanly re-assimilates upon exit.

  • ✓ Instant extraction of 2D coordinates & heading
  • ✓ Zero double-counting during boundary crossing
  • ✓ Ready for Bevy ECS and sumo-rs
Formal Formulations

Macroscopic Traffic Flow Equations

Standardized hydrodynamic traffic flow principles implemented in uxsim-rs.

01. Greenshields Model
$$v(k) = v_f \left(1 - \frac{k}{k_j}\right)$$ $$q(k) = v_f \left(k - \frac{k^2}{k_j}\right)$$

Linear decrease of space-mean speed with density; parabolic flow-density curve with peak capacity at \(k_c = k_j / 2\).

02. Newell Triangular
$$q(k) = \min\left(v_f k, \; w (k_j - k)\right)$$

Constant free-flow velocity branch and constant backward shockwave speed \(w\) branch, common in urban arterial modeling.

03. Rankine-Hugoniot Shockwave
$$w_{\text{shock}} = \frac{q_2 - q_1}{k_2 - k_1}$$

Conservation of vehicles across discontinuities; governs the speed of queue spillback and recovery wavefronts.

04. Link Storage & Travel Time
$$K = k_j \cdot L \cdot \text{lanes}$$ $$\tau = \frac{L}{v(k)}$$

Finite physical storage limits triggering spillback when link reaches jam capacity \(K\).

Developer Quickstart

Drop Into Your Rust / Bevy Project

Start building complex road networks and running city-scale simulations in seconds.

Cargo.toml 
[dependencies]
uxsim-rs = "0.1"
glam = "0.29"
src/main.rs — Urban Arterial Network 
use glam::Vec2;
use uxsim_rs::prelude::*;
use uxsim_rs::{Link, RoadNetwork, TrafficSimulator};
use uxsim_rs::flow_model::{FlowModel, NewellTriangular};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut network = RoadNetwork::new();

    // 1. Add intersection nodes
    network.add_node(1, Vec2::new(0.0, 0.0))?;
    network.add_node(2, Vec2::new(500.0, 0.0))?;
    network.add_node(3, Vec2::new(1000.0, 0.0))?;

    // 2. Add road links (length: 500m, 2 lanes, urban Newell model)
    let flow_model = FlowModel::NewellTriangular(NewellTriangular::standard_urban());
    network.add_link(Link::new(12, 1, 2, 500.0, 2, flow_model))?;
    network.add_link(Link::new(23, 2, 3, 500.0, 2, flow_model))?;

    // 3. Initialize simulator with 1.0s timestep
    let mut sim = TrafficSimulator::new(network, 1.0);

    // 4. Inject trips (A* dynamic auto-routing)
    sim.add_trip(1001, 1, 3, 0.0)?;

    // 5. Step simulation
    for _ in 0..60 {
        sim.step();
    }

    println!("Simulation step completed successfully!");
    Ok(())
}

Bevy RenderBubble Handoff Loop 

use glam::Vec2;
use uxsim_rs::handoff::RenderBubble;

fn sync_traffic_bubble(sim: &mut TrafficSimulator, player_pos: Vec2) {
    let bubble = RenderBubble::new(player_pos, 150.0, 25.0);

    // 1. Query macroscopic vehicles in bubble
    let entering = sim.query_vehicles_in_bubble(&bubble);
    for veh_id in entering {
        if let Ok(handoff) = sim.handoff_to_micro(veh_id) {
            // Spawn high-fidelity Bevy 3D entity
            spawn_bevy_micro_car(
                handoff.world_position,
                handoff.forward_direction,
                handoff.speed
            );
        }
    }
}
